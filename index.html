Про мене

Студент спеціальності «Кібербезпека» у Національному університеті «Львівська політехніка». Паралельно розвиваю навички у програмуванні мікроконтролерів, системному програмуванні, веброзробці та мережах. Цікавлюся Embedded-розробкою та створенням надійних і захищених систем.

Технічні навички

  • Програмування: C, C++, Python, базові знання JavaScript.
  • Embedded: Arduino, AVR, GPIO, робота з регістрами DDR, PORT та PIN, основи роботи з мікроконтролерами.
  • Мікроконтролери: базове розуміння архітектури AVR та принципів роботи з апаратними ресурсами мікроконтролера.
  • Електроніка: робота з електронними схемами, кнопками, світлодіодами, OLED-дисплеями, сервоприводами та EEPROM.
  • Python: CLI-утиліти, робота з файлами, базова автоматизація, OpenCV та MediaPipe.
  • Мережі: TCP/IP, базові мережеві протоколи, IP-адресація, OSI Model, Cisco Packet Tracer.
  • Кібербезпека: основи контролю доступу (RBAC), шифрування, аналіз паролів та базові принципи захисту інформації.
  • Інструменти: Linux (Ubuntu), Git, GitHub, VS Code, Arduino IDE, PlatformIO.

Досвід роботи / Проєкти

Embedded / Arduino — Electronic Lock

Розробка електронного замка на Arduino Uno з використанням C/C++. Реалізовано введення PIN-коду, керування сервоприводом, OLED-дисплеєм, кнопками та світлодіодами. Для зберігання PIN-коду використано EEPROM. Реалізовано роботу з GPIO та AVR-регістрами на низькому рівні.

Вивчення C та Embedded Programming

Вивчення мови C: змінні, умови, цикли, функції, масиви, вказівники, структури та робота з пам'яттю. Практика роботи з AVR-регістрами DDR, PORT та PIN, а також основи роботи з мікроконтролерами.

Python — навчальні проєкти

Практика Python у межах навчальних проєктів з кібербезпеки: CLI-утиліти, аналізатори надійності паролів, системи розмежування доступу (RBAC), алгоритми шифрування та робота з OpenCV і MediaPipe.

Мережі та кібербезпека

Практика проєктування мережевих топологій у Cisco Packet Tracer, робота з комутаторами та маршрутизаторами, налаштування мережевої взаємодії та вивчення основ мережевої безпеки.

Інструменти розробки

Робота з Git та GitHub, PlatformIO, Arduino IDE, VS Code та Linux. Створення та ведення власних проєктів, компіляція, налагодження та організація структури програм.
